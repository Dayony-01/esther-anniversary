# esther-anniversary

A premium, static anniversary gift website designed for Netlify.

## Files
- `index.html`
- `style.css`
- `script.js`

## To deploy on Netlify
1. Upload this folder to Netlify.
2. Keep the files at the root level.
3. Publish the site.

## Notes
This is a static HTML/CSS/JS project with no build step.
